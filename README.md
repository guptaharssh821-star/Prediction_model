## 🤖 General Machine Learning Prediction Model
A general-purpose machine learning prediction application built using Python, NumPy, pandas, scikit-learn, and Streamlit.This project implements Multiple Linear Regression from scratch using NumPy, with the mathematical 
calculations for training, prediction, and model evaluation written manually rather than relying on a prebuilt regression estimator.

The application provides an interactive Streamlit interface where users can upload their own CSV datasets, select a target variable, train the model, evaluate its performance, and generate predictions for new data.

### Features :-

1.Upload a CSV dataset.

2.Select the target column.

3.Train a multiple linear regression model.

4.View model evaluation metrics.

4.Enter values to generate predictions.


### ▶️ How to Run the Application

1. Download or clone this repository from GitHub.

2. Open the project folder in VS Code.

3. Install the required libraries:

   ```
   pip install -r Requirement_.py
   ```

4. Run the Streamlit application:

   ```
   streamlit run f_6_Multi_Variate_General_pro_.py
   ```

5. Open the local URL shown in your terminal (usually `http://localhost:8501`) in your browser.

**That's it!** Upload your CSV dataset, select the target column, train the model, and generate predictions.
